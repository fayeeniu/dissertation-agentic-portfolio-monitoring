\chapter{Research Design and Methodology}
\section{Applied design-science strategy}

An applied design-science strategy fits this dissertation because its research object is a purposeful portfolio-reporting artefact for a bounded organisational reporting problem, together with the evaluation of that artefact, rather than a model demonstration alone. Design science combines the construction of an artefact with rigorous evaluation of its utility, quality and efficacy \citep{hevner2004design}. The Design Science Research Methodology likewise connects problem definition and objectives to design, demonstration and evaluation against observed outcomes \citep{peffers2007dsrm}. The local workflow is therefore the constructed evaluand; implementation alone cannot establish utility or answer the research questions.

The student acts as both builder and evaluator, which creates a direct confirmation-bias threat. The protocol addresses this through frozen conditions, measures and stop rules; versioned code, schemas and dataset manifests; independent or adjudicated reference labels; blinded scoring where practical; and complete accounting of failures and exclusions. Reproducibility depends on retaining sufficient code, data, procedural and reporting detail \citep{pineau2021reproducibility}. Risk measurement should also document uncertainty, tested conditions and independent-review limits \citep{nist2023airmf}. These controls constrain discretionary reinterpretation but do not remove researcher judgement.

Repository code, tests and contracts can establish what is implemented and which engineering invariants pass; they are not empirical findings about effectiveness, efficiency or human benefit. Such findings require execution of the frozen comparison protocol against stated objectives \citep{hevner2004design,peffers2007dsrm}, supported by reproducible artefacts and bounded reporting \citep{pineau2021reproducibility}. Synthetic D0 outcomes remain mechanism evidence. Manual, restricted-data, human-review and live public-web comparisons remain held until separately authorised and frozen; unavailable or unlabelled outcomes remain null, never zero. Figure~\ref{fig:meth-design-science-evidence-chain} summarises this non-empirical evidence-state boundary \citep{nist2023airmf}.

\section{Evaluand and experimental conditions}

The evaluand is the complete workflow configuration, not an abstract model or leaderboard. For each condition, the project protocol binds the input contract, catalogue, source access, agent decomposition, verification rule, human involvement, prompt and schema versions, compute environment, and stop criteria. This definition keeps observed outcomes attached to a specified artefact and context. Design science requires a viable artefact and rigorous evaluation against relevant objectives \citep{hevner2004design,peffers2007dsrm}, while structured reporting makes intended use, version and evaluation procedures visible \citep{mitchell2019modelcards}.

Within the RQ1--RQ3 research contract, the protocol pre-specifies four conditions for later freeze. C0 is an authorised practitioner completing the existing manual workflow under the same frozen input and source-access window, with timing and corrections recorded; any tool or model assistance must also be logged. It remains protocol-only. C1 is one deterministic extraction and composition path using the common catalogue and normaliser without an independent verifier; it retains available provenance and is implemented only on synthetic labelled cases. Comparing stated objectives with observations, rather than construction, is the evaluation step \citep{peffers2007dsrm}, and reproducibility requires procedural detail \citep{pineau2021reproducibility}.

C2 adds bounded planner, resolver, collector, extractor, normaliser, verifier and composer roles. Its separately recorded verifier controls support eligibility, and no human edit occurs before scoring; its current evidence is likewise synthetic. C3 then passes C2 output through the versioned human-review interface, retaining edits, approvals and rejections and scoring pre-review and approved outputs separately. The workflow exists, but human results remain protocol-only. Comparable execution requires the same canonical definitions, reporting period, source-access window and frozen gold reference. Documented test conditions, measures and independent review support interpretable comparison \citep{nist2023airmf}, while retained procedures and artefacts support reproducibility \citep{pineau2021reproducibility}.

Table~\ref{tab:meth-condition-matrix} records the conditions; the protocol remains draft-for-domain and ethics review. Manual, restricted-data and human-user execution stays held until ethics and data authority, gold-reference construction and protocol freeze are complete; affected outcomes remain null. The implemented but live-unrun public-web company-research path is an engineering case study, not an experimental condition within C0--C3 or the frozen RQ1--RQ3 research contract. Any future official-adapter-only versus LLM-assisted comparison therefore remains held rather than becoming substitute evidence. Explicit version, context and out-of-scope reporting supports this separation \citep{mitchell2019modelcards}, while leakage evidence cautions against generalising across unmatched information boundaries \citep{kapoor2023leakage}.

\section{Dataset tiers and freeze protocol}

Figure~\ref{fig:meth-dataset-freeze-timeline} distinguishes engineering from authorised empirical evidence. D0 comprises fictional, labelled, visible adversarial fixtures supporting regression and mechanism evidence, not real portfolio performance. The current manifest hash-pins the D0 file and records \texttt{benchmark:d0}, source version, test-only partition policy and permitted use. The loader computes the manifest checksum, validates the declared dataset checksum, source-version/classification and entity/period partition consistency; other \texttt{benchmark:} namespaces and policy strings remain accepted. A separate operational-ID guard rejects benchmark-prefixed identifiers where invoked. Synthetic financial tables can provide labelled task material \citep{bradley2024synfintabs}; datasheets support provenance and permitted-use documentation \citep{gebru2021datasheets}.

D1 is the smallest separately authorised pilot or calibration subset sufficient to clarify codebook and label instructions, estimate labelling workload, disagreement and timing variance, test capture forms and code, and support sample-size or precision planning. Its sampling and collection window must be documented; results are labelled pilot and excluded from confirmatory estimates unless the analysis plan pre-declares the study exploratory. Dataset documentation should state motivation, composition, sampling, collection and validation \citep{gebru2021datasheets}; reproducibility also requires enough procedural and analytical detail to repeat the experiment \citep{pineau2021reproducibility}. D1 currently remains protocol-only.

Before D2 is opened, freeze catalogue aliases and rules, schemas, prompts and model choices, code and environment, metrics and denominators, analysis, dataset and source manifests, and reference versions. D2 is a company-period final out-of-sample set whose manifest remains sealed, with no path, checksum or development access. It must not be inspected, tuned against, or used to repair connectors or rules or select models; any post-access change creates a new exploratory run. Clean train-test separation and protection from non-independent or temporal leakage are necessary because leakage can inflate performance estimates \citep{kapoor2023leakage}; code, data and experimental reporting support reproducibility \citep{pineau2021reproducibility,mitchell2019modelcards}.

Partitioning groups all records for the same company, report and entity-period so related units cannot cross evaluation partitions; repeated fields are clustered and analysis must aggregate or use cluster-aware methods. This prevents a larger field count from being treated as independent evidence. Participant observations are authorised executions of C0 or C3, not an additional D3 dataset tier. D2 remains sealed, while C0 and human-result C3 remain held pending authority and protocol freeze. Dataset lifecycle documentation should expose sampling and exclusions \citep{gebru2021datasheets}, and non-independent test data require explicit leakage controls \citep{kapoor2023leakage}.

\section{Gold-reference construction and source-access parity}

Gold-reference construction will begin with a versioned codebook derived from the canonical data dictionary. Two authorised domain reviewers will independently receive the same frozen source bundle. For each company-period, they will label the canonical value or typed missing state, eligible evidence, sourceability, period, claim support and required report section. Independent coding supports reliability assessment but cannot establish validity, because reviewers may agree consistently and still be wrong \citep{artstein2008agreement}; independent assessment and documented test methods make evaluation inspectable \citep{nist2023airmf}.

Raw agreement will be reported before adjudication. A chance-corrected statistic will be added only when the sample size, label type and category distribution support its assumptions; no universal agreement threshold will be imposed. Reviewers will adjudicate disagreements, record the reason and update the codebook version, after which the reference and manifest will be frozen before scoring. Manual reports and system outputs remain comparison conditions rather than truth, and scoring will be blind to condition where practicable \citep{artstein2008agreement,pineau2021reproducibility,nist2023airmf}.

Source-access parity will freeze an eligible-source manifest and availability cutoff for each company-period. Comparable conditions will receive the same canonical definitions, period, source window and gold reference. Inaccessible, deleted, paywalled, login-only and later-published states will be recorded. Retrieval time is distinct from publication and availability time, and post-cutoff material cannot support a historical claim. Each admitted claim will preserve its exact locator or span and source policy, because citation presence alone does not establish complete or correct support \citep{gao2023alce,gebru2021datasheets,pineau2021reproducibility}.

Table~\ref{tab:meth-reference-parity-matrix} maps the codebook, reviewer labels, adjudication reasons, source manifest and scoring deviations into one frozen record. This supports reproducible comparison without treating adjudication as infallible or converting a source into truth \citep{artstein2008agreement,pineau2021reproducibility}. At present, the gold reference has not been constructed or frozen, so C0--C3 scores remain unavailable and no empirical outcome is claimed. Documented uncertainty and unavailable measures must remain visible rather than being replaced by assumed values \citep{nist2023airmf,gebru2021datasheets}.

\section{Measures and denominator rules}

Evaluation units are field, claim, report, workflow and reviewer. A field is one company--metric--period observation; a claim is one reportable proposition; the others follow the frozen protocol. Repeated fields within a company or report are clustered rather than independent, so analysis will aggregate at report or company level or use cluster-aware methods. No acceptance threshold is pre-populated. Table~\ref{tab:meth-metric-denominator-matrix} records each measure's numerator, denominator, exclusions and zero-denominator rule; an undefined result remains null, not zero \citep{artstein2008agreement,pineau2021reproducibility,nist2023airmf}.

Claim precision is supported emitted claims divided by all emitted claims eligible for scoring; recall is correctly emitted gold claims divided by all gold claims required by scope. F1 is their harmonic mean only when both are defined. The unsupported-claim rate divides emitted claims lacking gold or evidence support by emitted claims; the claim-support rate applies the frozen support rule to the same denominator. Contradiction-detection recall divides correctly flagged gold conflicts by all gold conflicts. These project formulas separate correctness, citation recall and citation precision \citep{gao2023alce,nist2023airmf}.

Extraction measures include strict schema validity, exact field accuracy, type-specific normalisation, currency or unit correctness, missing-state accuracy with a separate blank-versus-zero error matrix, and identity accuracy and coverage. Provenance and report measures include provenance completeness, locator validity at capture, required-section completeness, factual-error count and severity, and transparency for missing, conflicted or stale items. Provenance completeness uses eligible emitted claims with required source, locator, applicable publisher, retrieval time, checksum and period over eligible emitted claims. Other scorer denominators must be frozen before use, not improvised after results \citep{nikiforova2020quality,gao2023alce,gebru2021datasheets}.

Efficiency separates active human minutes from elapsed time while recording machine-stage durations, retries, input and output tokens, reviewer edit events, optional edit distance, and failure or rerun counts. LLM or API cost uses only the provider's official price effective on the execution date, with formula, units, currency and token quantities recorded; otherwise it is null, not estimated. Reliability will report exact outcome-vector consistency for deterministic repeats, field or claim agreement for fixed stochastic configurations, completion and schema validity across repeats, and failure-category distributions \citep{pineau2021reproducibility,mitchell2019modelcards,nist2023airmf}.

Usability belongs only to separately authorised C3 execution under an approved instrument and protocol. Candidate observations include task success, time, decision reversals, confidence calibration and a suitable validated scale where licensed, plus consented qualitative feedback coded under a pre-defined scheme. Reviewer or event layers with no authorised or labelled cases remain null and cannot be converted to zero. This preserves the distinction between an implemented review interface and measured reviewer benefit \citep{amershi2019guidelines,nist2023airmf,artstein2008agreement}.

\section{Statistical and qualitative analysis}

Analysis will publish the flow of eligible, excluded, failed and scored units, with reasons for losses. Per-condition denominators and descriptive distributions will precede any test. Comparisons will pair the same company-period or claim wherever conditions share units. Repeated fields within one company or report will not be counted as independent evidence; results will instead be aggregated at report or company level or use cluster-aware intervals. This preserves the experimental unit and exposes attrition rather than hiding it \citep{demsar2006comparisons,kapoor2023leakage,pineau2021reproducibility}.

For paired binary outcomes, the current draft analysis plan may use an exact paired method. Non-normal time and edit-burden differences may use a paired Wilcoxon-style analysis, but only when sample size, pairing, distributional and measurement assumptions support it. Estimates will be accompanied by effect sizes and uncertainty; interval construction will respect the resampling unit and document the method. Non-parametric labels do not remove design assumptions, while confidence-interval coverage can be inaccurate in finite samples \citep{demsar2006comparisons,diciccio1996bootstrap,nist2023airmf}.

Any multiplicity correction will be declared prospectively; otherwise affected comparisons will be labelled exploratory. Stratification by metric type, sourceability, missingness, conflict or staleness, and identity difficulty will occur only where the sample supports interpretable denominators. Sensitivity analyses will repeat conclusions with failures included and with each justified exclusion, preserving negative, null and regressive outcomes. The exact test, interval method and sample size remain TO FREEZE after D1 variance and annotation evidence plus supervisor and statistical review \citep{demsar2006comparisons,pineau2021reproducibility,kapoor2023leakage}.

Qualitative error analysis will apply pre-defined families ID, EXT, NORM, TIME, PROV, VER, REP, SEC and HITL to eligible cases, with severity definitions TO FREEZE before scoring. The record will retain definitions, codes, coder disagreements and reasoned adjudication, protocol deviations and negative cases. Agreement may support reliability assessment but does not establish validity, and risk assessment must preserve uncertainty and documented review limits \citep{artstein2008agreement,gale2013framework,nist2023airmf}.

If authorised C3 reviewers provide consented feedback, a framework-style case-by-code matrix will connect summaries to source records for comparison within and across cases. Analysis will document framework revisions, reflexive notes and codebook departures without forcing feedback into favourable themes. Until authorised material exists, this branch remains unavailable and no thematic finding will be claimed. Figure~\ref{fig:meth-analysis-decision-flow} summarises this non-empirical decision flow \citep{gale2013framework,artstein2008agreement,pineau2021reproducibility}.

\section{Ethics, leakage prevention, and reproducibility}

Ethical use begins with authority and classification, not technical availability. Each input will be classified as restricted, internal, public or synthetic before admission, with its purpose and access basis recorded. Public availability alone will not authorise reuse. Participant observation and restricted data will remain unavailable unless ethics and data owners approve the purpose, consent process and storage route. Restricted material will stay local and will not be sent to an external model without separate recorded authority \citep{gebru2021datasheets,cddo2023genai,nist2023airmf}.

Before D2 is opened, the catalogue, aliases, schemas, prompts, model choices, code, environment, metrics, analysis and manifests are to be frozen. D1 may inform that freeze only after separate authority; D2 remains sealed and cannot be inspected, repaired or used to choose rules. Any post-access change will create a new exploratory run rather than a confirmatory result. This separation addresses leakage where held-out information influences preprocessing, selection or evaluation \citep{kapoor2023leakage,pineau2021reproducibility}.

Each authorised final run will retain a Git revision and diff manifest that excludes restricted data, platform and dependency versions, migration revision, dataset and source manifests, availability cutoff, catalogue, codebook, prompt, schema and model versions, secret-free configuration, run identifiers, failures, outputs, decisions, scoring code and generated artefact hashes. The record will also identify deviations, their reasons and the affected evidence class. Hashes will show byte-level change but will not establish truth, ethical authority or replication in another setting \citep{pineau2021reproducibility,mitchell2019modelcards,gebru2021datasheets}.

Collection will stop if authority or consent is unclear, a credential is exposed, unexpected personal data appears, source terms are breached, restricted data would cross an unapproved processor, or the D2 seal is broken. The event will be recorded, never bypassed. The student is the builder-evaluator; fixed questions, a future protocol freeze, independent, adjudicated labels, error accounting and narrow conclusions are controls against confirmation bias. Table~\ref{tab:meth-evidence-control-matrix} summarises this control boundary. None implies ethics approval, participant execution or completed evaluation \citep{nist2023airmf,pineau2021reproducibility,kapoor2023leakage}.
